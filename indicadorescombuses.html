Guía rápida: Operación por rutas

Al entrar en esta pestaña se abre el filtro de tiempo para que el usuario seleccione el periodo y luego vea pasajeros y viajes por ruta.
1. Escoge el tipo de filtro Año, mes, día o rango de fechas. La app abre el panel automáticamente.
2. Selecciona los datos Marca uno o varios años, meses o fechas. También puedes usar Todos o Ninguno.
3. Aplica el filtro El botón Aplicar filtros actualiza las tablas y los gráficos de pasajeros y viajes.
4. Lee las barras Los gráficos muestran los valores directamente sobre las barras para lectura rápida.

Controles visuales de gráficos

Estos controles afectan todos los gráficos: valores sobre barras, altura visual y tablas auxiliares.
Muestra el número directamente sobre cada barra para que el usuario no dependa solo del mouse.
Compacto es ideal para pantalla completa; completo sirve para revisión detallada.
La altura amplia mejora la lectura en pantallas grandes o televisores.
Permite dejar solo el gráfico visible cuando se quiera una vista más limpia.
